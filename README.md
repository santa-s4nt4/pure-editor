# pure

ただ、書く。macOS と iOS のための静かな Markdown エディターです。

Tauri v2 / SolidJS / TypeScript / CodeMirror 6。トップには記事のタイトルとタグを最終編集日の新しい順に並べます。記事画面はツールバーや常設サイドバーを持ちません。

## 起動

Node.js 22.12 以上を使用します。

```sh
npm install
npm run dev
```

`http://localhost:1420` でブラウザ版を開けます。文章・画像は IndexedDB に保持します。ブラウザのサイトデータを削除すると消えるため、普段の執筆にはネイティブ版を使用してください。

macOS アプリには Rust 1.90 以上と Xcode Command Line Tools が必要です。実行対象は macOS 14.5 以降 / iOS 17.5 以降です。

```sh
npm run tauri dev
npm run tauri build
```

iOS は macOS 上の Xcode と Apple の開発署名を使用します。初回に Xcode プロジェクトを生成し、署名チームを設定してください。

```sh
npm run tauri ios init
npm run tauri ios dev
npm run tauri ios build
```

## 使い方

| 操作 | ショートカット |
| --- | --- |
| ノート検索 | ⌘ L |
| ページ履歴を戻る・進む | ⌘ ⇧ ← / ⌘ ⇧ → |
| 箇条書きのインデント | Tab / ⇧ Tab |
| すぐに新しい記事を書く | ⌘ N |
| 現在の記事を削除 | ⌘ ⇧ Delete |
| 設定 | ⌘ , |
| 今すぐローカル保存 | ⌘ S |
| パレットを閉じる | Esc |
| ホームへ戻る | Esc をすばやく2回 |
| リンク・タグを開く | クリック / タップ |

iPhone では右下の「···」でノート一覧を開き、右上の「ホーム」からトップへ戻れます。画面の左端から右へスワイプすると履歴を戻り、右端から左へスワイプすると進みます。トップの記事は左にスワイプすると削除ボタンが現れ、深くスワイプするとそのまま削除します。通知の「元に戻す」で復元できます。縦スクロール、長押しの文字選択、複数指の操作では移動・削除しません。Paper 文書の削除は Dropbox 側で行います。パレットで名前を入力し「つくる」を選ぶと新しいノートになります。タグやタイトルを検索できます。トップのタグは最大3件で、続きがある場合は「…」を表示します。記事画面からホームへ戻るには Esc をすばやく2回押します。記事画面にはホームボタンを表示しません。

- `[タグ]` はタグです。同じタグを持つ記事が2件以上あるとき、クリックでその記事一覧へ移動します。1件だけなら移動しません。タグの記法はそのまま保存します。`#タグ` はタグとして扱いません。パレットでは `[タグ]` と入力するとタグの完全一致で探せます。
- `[https://example.com]` は URL、`[https://example.com 名前]` は名前付きリンクです。クリックするとブラウザで開きます。保存時は標準 Markdown リンクに変換し、開くと元の記法に戻します。通常は角括弧と名前付きリンクの URL を隠し、下線も表示しません。行にカーソルや選択範囲が入ると、角括弧を含む元の記法を表示します。リンクを開く範囲は表示文字の上だけです。`[` の入力で `]` を補完します。
- コード、画像、既存リンク、タスクのチェックボックスは変換しません。別名やタイトル付きのリンクはそのまま保ちます。
- 最初の `# 見出し` が記事タイトルになります。見出しの `#` は画面から隠します。新規記事は先頭に `# ` を用意し、最初の行だけ「タイトル」と仮表示します。ファイル名はタイトル変更後も維持するため、ほかの記事からの参照を壊しません。
- YouTube / Vimeo の URL を貼ると動画を表示し、元のリンクを隠します。動画の行へカーソルを戻すと記法を編集できます。`- [URL]` の箇条書きや通常の Markdown リンク、URL 単独の行にも対応します。
- `- ` の箇条書き内にも画像を置けます。画像を貼り付けるかドラッグすると、長辺 1600 以下・品質 0.85 の WebP に変換して選択した画像フォルダに保存します。画像がある行からカーソルを移すと記法を隠します。ファイル・Clipboard items・HTML の data URL・macOS の画像クリップボードに対応します。アプリでは Canvas で縮小した RGBA を Rust の libwebp で品質85に変換するため、WebKit が WebP の書出しを持たない環境でも保存できます。
- `---` の後にスペースを入れると横線、`[]` の後にスペースを入れるとチェックボックスになります。チェックした行は灰色の取り消し線で表示します。
- 入力が止まって 2 秒後に保存します。移動・終了時にも保存し、入力中の文章を回復用ジャーナルに保持します。
- 記事削除はローカルの `.trash/` に内容を残します。削除直後の通知の「元に戻す」から復元できます。
- Mac の記事画面では、左側の余白にポインターを置くと見出しの目次がフェード表示されます。クリックでその位置に移動できます。長い目次はスクロールでき、専用のスクロールバーは表示しません。
- トップの「pure」は線のハッチングがゆっくり動くワードマークです。アイコンの元画像と固定パラメータは [ブランド表示の説明](docs/branding.md) にまとめています。

ネイティブ版の YouTube は、動画を表示するときだけ `127.0.0.1` のランダムポートに専用の HTML 配信を起動します。WebKit のカスタムスキームで失われる HTTP Referer を補うためです。この配信は動画 ID を受け取るだけで、ノートや設定ファイルへのアクセス機能はありません。

## 保存と R2

Cloudflare 側の準備から Mac・iPhone の初回同期までの手順は、[R2 の設定ガイド](docs/r2-setup.md) を参照してください。

初期保存先はアプリデータ内の `Documents/Notes`、画像はその中の `assets` です。macOS では設定から **Markdown と画像のフォルダを別々に選べます**。実ファイルには両フォルダの位置に合わせた相対 URL を書き出すため、ほかの Markdown アプリでも画像を参照できます。画像フォルダだけを変更した場合、既存画像をコピーして記事内の参照を更新します。元の画像はそのまま残します。iOS はサンドボックス内に保存します。

設定で Cloudflare R2 の **S3 API エンドポイント**（`https://<account-id>.r2.cloudflarestorage.com`）、バケット、読み書き権限の Access Key ID / Secret Access Key を入力します。同期用の専用バケットを推奨します。Secret Access Key は macOS / iOS の Keychain に保持し、ノートや設定 JSON には書き込みません。通信はネイティブ HTTP と AWS Signature V4 を使うため CORS 設定は不要です。

`_sync.json` に各ファイルの相対パス・Unix ミリ秒の更新時刻・SHA-256 を保持します。起動、前面への復帰、接続復帰、保存後に差分を同期します。オンライン中は 1 分ごとにも再試行します。ローカル保存はネットワークを待ちません。

同期済みのハッシュを `_sync-state.json` に保持し、両端末で編集された場合はローカル版を `名前 (conflict 日時-ID).md` に残します。R2 への書込みはオブジェクトとインデックスの ETag を条件にして競合を検出し、取得内容の SHA-256 も検証します。R2 内の `_pure/objects/<sha256>` に確定した内容の不変コピーを保持し、ファイルとインデックスの書込みの間でアプリが終了しても復元できるようにします。この領域は手動で削除しないでください。アプリ内での削除はインデックスに削除履歴を残し、ほかの端末にも伝えます。削除された記事の以前の内容は復元用に保持されます。画像のパスは同期時に `assets/` に正規化するので、端末ごとの保存先の違いを吸収します。

同じバケットをほかのアプリから変更する場合も `_sync.json` の更新が必要です。バケット認証情報がない状態の検証では、実サービスへの疎通は確認できません。

## Dropbox Paper

設定から Dropbox に接続すると、⌘ O で `.paper` を開き、元の名前を維持して同じ Dropbox Paper 文書を編集できます。企業アカウントでは管理者の接続許可が必要な場合があります。接続準備、対応範囲、保存・競合処理は [Dropbox Paper の手順](docs/dropbox-paper.md) を参照してください。実アカウントでの動作は未確認です。

## 見た目の調整

- `src/styles/tokens.css`：色、文字サイズ、行間、字間、紙の余白。
- `src/styles/typography.css`：游明朝と Times New Roman の混植。欧文の `size-adjust` はこのファイルで変更します。
- `src/styles/layout.css`：配置とパレット、画像・動画。

CodeMirror の独自スタイルも外部 CSS にまとめています。Tailwind と `EditorView.theme()` は使用していません。設定の「外観」からライト・ダーク・自動を選べます。自動は OS の外観変更に追従します。ライトは白地と黒文字、ダークは参考画像に合わせたチャコール `#46474b` とやわらかい白です。リンク・タグと文字選択はどちらも灰色です。広いウィンドウでは本文幅も広がります。本文は [stone の参照記事](https://stone-type.jp/tebiki/542/) に合わせて 14〜15px 相当、行間 2、字間 0.04em に設定しています。iPhone などのタッチ画面では、入力時の自動ズームを避けるため本文を16px相当にしています。

タグは `[タグ名]` の途中で既存タグの候補が出ます。入力で絞り込み、↑↓ と Enter、またはタップで選択できます。Escape で候補を閉じます。Tab / Shift+Tab のインデント幅は3文字分です。

Mac ではトラックパッドの左右スワイプでページ履歴を戻る・進む操作ができます。縦スクロール・ピンチ操作・横スクロール領域とは区別し、同方向の慣性中は連続で移動せず、指を離さない反転や次のジェスチャーは受け付けます。画面端には小さな矢印が出ます。動画プレイヤー内など、外部 iframe が操作を受け取る領域では使えません。Mac はネイティブのスクロールイベントを受け取り、ページ切り替え後もカーソルを動かさず操作できます。実機のトラックパッドでの操作感は未確認です。

左余白の目次は、画面に収まる場合はその上から本文をスクロールできます。長い目次は目次自体をスクロールできます。

Markdown のファイル名は `記事タイトル--32桁のID.md` です。同じ題名の記事も別々に保存し、題名を変更すると保存時にファイル名が追従します。ID は維持します（大文字・小文字だけの変更では名前を維持）。既存ファイルは更新版の初回起動時に自動移行し、本文中のローカル Markdown リンクと同期インデックスも更新します。移行前の原本は保存先の `.trash/renamed-…/` に残します。移行用の `_note-renames.json` は旧名から新名への対応表です。

Mac のトップページで記事タイトルをダブルクリックすると、トップページを残して、通常と同じ編集画面が別ウィンドウで開きます。本文の編集・画像の貼り付け・タグ候補・目次・記事の操作・保存に対応し、保存後の内容やタイトル変更はほかのウィンドウにも反映します。メインウィンドウを閉じても編集と保存を続けられます。同じ記事を同時に変更した場合は、先に保存された本文を競合コピーに残します。シングルクリックは OS のダブルクリック判定時間を待って開き、キーボードと iPhone のタップでは即座に開きます。公開記事は、トップのタグと同じ行に小さな地球儀アイコンを表示します。
